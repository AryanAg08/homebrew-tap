# homebrew-tap

Homebrew formulae.

```bash
brew install AryanAg08/tap/pulse
brew install AryanAg08/tap/crew
```

## pulse

A context-aware assistant for developers that mostly stays quiet. It reads your
real work state — git, GitHub, edit activity — and speaks only when the evidence
justifies an interruption.

Source: https://github.com/AryanAg08/pulse

After installing:

```bash
pulse init      # asks about your day and your routines
pulse doctor    # checks the install and names the fix for anything broken
```

## crew

Run many Claude Code sessions in parallel — across branches and across projects —
from one terminal screen. Each session gets its own git worktree, a sidebar to
switch between sessions, live status, token usage and a changes view.

Source: https://github.com/AryanAg08/crew

After installing (needs [Claude Code](https://claude.com/claude-code) on your PATH):

```bash
crew
```
